# Services Used

- Google cloud console  
    -  Used to handle authentication
    - Totally free

- Supabase  
    - Services used for **DB only** and the free tier got 500 MB database size which cannot be maxed out anytime soon as the context stored is only texts. More info regards their pricing is stated here: https://supabase.com/pricing.
    - Note: Only DB feature is used in supabase.

- Stripe. 
    - Used for the payment management: Proper breakdown for stripe can be found here https://stripe.com/pricing

- Uploadthing  
    - Used for handling the media contents being uploaded where the limit for the free tier is 2GB and pricing for upgrade stated here https://uploadthing.com/pricing

- Vercel  
    - Manages the deployment 
    - Pricing fiar and can be maxed out when there's **a lot** of traffic.
    - Pricing statetd here: https://vercel.com/pricing
